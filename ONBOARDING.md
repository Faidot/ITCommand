## Your Setup Checklist

### Codebases
- [ ] ITCommand — https://github.com/Faidot/ITCommand — the monorepo, containing:
  - `itcommand_backend/` — Django REST API (Python). Create a venv and `pip install -r requirements.txt`, then `python manage.py migrate && python manage.py runserver`.
  - `itcommand_frontend/` — Next.js 15 app (TypeScript). `npm install && npm run dev`.
  - `it-command-extension/` — Chrome extension (MV3). Load unpacked via `chrome://extensions`.

### MCP Servers to Activate

### Skills to Know About
- /model — switch which Claude model powers your session (e.g. Opus for hard problems, Haiku for quick edits).
- /code-review — review your current branch diff for bugs before opening a PR.
- /init — generate a CLAUDE.md for a repo so Claude understands the project conventions from the start.
